# Documentos do repositório

Os documentos de processo foram escritos em momentos diferentes, a maioria como instrução para um agente de código. Cada um começa com um bloco que diz para quem foi escrito e se ainda vale. Eles ficam nos lugares originais, porque há referências cruzadas entre eles.

## Para quem opera ou usa o serviço

- [operacao.md](operacao.md): configurações de painel (Vercel, GitHub, Zenodo), conferências depois do deploy e como publicar uma versão.
- [USO-DE-IA.md](USO-DE-IA.md): declaração de uso de IA no projeto e como os resultados foram conferidos.
- [licencas-dependencias.md](licencas-dependencias.md): resumo gerado das licenças das dependências de produção.
